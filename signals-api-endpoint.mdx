---
title: "Signals API Endpoint"
---

## Overview

Creates a new signal and assigns it to a user using their email address.

## Request

POST

### Endpoint

https://api.terrakotta.ai/partner-signals

### Headers

```http
Content-Type: application/json
Authorization: Bearer YOUR_API_KEY
```
### Body

```json
{
  "userEmail": "email of the user to receive the signal",
  "body": "customizable based on partner specifications",
}
```
