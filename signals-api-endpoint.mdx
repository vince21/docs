---
title: "Signals API Endpoint"
---

## Overview

Creates a new signal and assigns it to a user using their email address.

## Request

POST

### Endpoint

/signals

### Headers

```http
Content-Type: application/json
Authorization: Bearer YOUR_API_KEY
```
### Body

```json
  {
    "email": "user@company.com",
    "company": "Acme Corp",
    "signal": {
      "type": "tenant_expansion",
      "confidence": 0.87,
      "source": "broker_call",
      "details": {
        "location": "Seattle",
        "sqft": 15000,
        "timeline": "Q3"
      }
    }
  }
```
